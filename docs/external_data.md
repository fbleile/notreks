# External benchmark data

External benchmark inputs are deliberately not committed to this repository.
The repository stores importers, URLs, validation rules, and manifest schemas;
the generated arrays and upstream caches belong in an experiment output
directory or an approved shared data location.

## CausalAssembly

The importer uses the official static `n=500` CSV and ground-truth JSON:

```bash
notreks-external-import causalassembly data/causalassembly --download
notreks-external-check data/causalassembly/manifest.json
notreks external-plan data/causalassembly/manifest.json \
  plans/causalassembly.json --name causalassembly \
  --methods flop flop_notreks --fractions 0 0.25 1 \
  --attempts flop:20 --attempts flop_notreks:20
```

The importer verifies the official node order, the fixed sample shape, finite
values, and the generated-artifact checksums. The manifest records the upstream
source and input-file checksums.

## CausalMan

CausalMan is generated by the official upstream simulator rather than
downloaded as a static array. Install the pinned upstream package and its
assets in the preparation environment, then run:

```bash
notreks-external-import causalman data/causalman_small \
  --variant causalman_small --seed 1001 --sample-size 5000
notreks-external-check data/causalman_small/manifest.json
notreks external-plan data/causalman_small/manifest.json \
  plans/causalman_small.json --name causalman-small \
  --methods flop flop_notreks --fractions 0 0.25 1 \
  --attempts flop:20 --attempts flop_notreks:20
```

The importer fails if the official package is unavailable; it never substitutes
a local generator. It removes intervention rows, selects observed continuous
variables, preserves projected directed and bidirected edges, and marks the
evaluation target as a latent-projection diagnostic rather than CPDAG SHD.

## Provenance rule

Keep the resulting `manifest.json`, upstream revision, package environment,
and command line with the experiment outputs. Do not copy large raw datasets
into the Git repository merely to make a plan syntactically complete.

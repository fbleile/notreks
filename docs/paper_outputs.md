# Paper output registry

`src/notreks/paper_outputs.py` is the canonical inventory of paper-facing
figures, tables, and auxiliary analyses. It records the expected input
artifact, the shared command or analysis entry point, and the scientific
scope of each output. It is deliberately separate from the figure renderer:
the renderer stays generic, while this file prevents paper-specific output
names and data selections from becoming implicit.

List the registry with:

```bash
PYTHONPATH=src python -m notreks.paper_outputs
```

Before a release, every listed input must either exist in the result archive or
be regenerated by the documented experiment plan. A paper figure should not
be created by an untracked notebook or an ad hoc shell pipeline.
